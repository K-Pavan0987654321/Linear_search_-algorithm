✅ What is Linear Search?

Linear Search is the simplest searching algorithm where we:
👉 Check each element one by one
👉 Until the required element is found or list ends

🧠 Simple Definition

Linear Search is a searching algorithm that sequentially checks every element in a list until the target element is found or the list ends.

📌 When Do We Use Linear Search?

✔ Data is small
✔ Data is unsorted
✔ Simplicity is more important than speed

🧩 Algorithm Steps

Start from the first element

Compare element with target

If match → return index

If no match till end → return -1

🧪 Example
List = [15, 8, 20, 5, 12]
Target = 20

Step-by-Step Check:
15 ❌
8 ❌
20 ✅ (Found)
